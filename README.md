# 2026 인천국제공항공사 생애주기 교육(이음·채움) 국외연수 안내책자

## 파일 구성 (폴더 없음 — img 하나만 폴더)
```
index.html    차수 선택 페이지
1.html        1차 진단과정 1차 (10.13~10.16)
2.html        2차 실행과정     (10.20~10.23)
3.html        3차 진단과정 2차 (10.27~10.30)
img/          공용 이미지
.nojekyll     (빈 파일, 그대로 두세요)
```

## 올리는 법
저장소 → Add file → Upload files 에서
위 5개(index.html, 1.html, 2.html, 3.html, .nojekyll)와 img 폴더를 한꺼번에 드래그 →
맨 아래 Commit changes.
